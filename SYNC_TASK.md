# Задачи для omnimap-sync

## Синхронизация DM сообщений между клиентами одного пользователя

**Контекст:** При отправке DM сообщения с одного клиента, второй клиент того же пользователя не получает это сообщение в реальном времени.

**Проблема:** В WebSocket событии `dm` отсутствует `recipient_id`, из-за чего frontend не может определить, что это собственное сообщение для текущего активного чата.

### Задача

- [x] В событии `dm` добавить `recipient_id` в data для сообщений, отправляемых отправителю (echo собственных сообщений)

**Текущий формат:**
```json
{
  "type": "dm",
  "data": {
    "sender_id": 123,
    "message": {
      "id": "uuid",
      "content": "текст",
      "created_at": "2024-01-01T12:00:00Z"
    }
  }
}
```

**Ожидаемый формат:**
```json
{
  "type": "dm",
  "data": {
    "sender_id": 123,
    "recipient_id": 456,
    "message": {
      "id": "uuid",
      "content": "текст",
      "created_at": "2024-01-01T12:00:00Z",
      "recipient_id": 456
    }
  }
}
```
